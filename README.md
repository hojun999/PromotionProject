# Lunar-Impact #

## 1. 프로젝트 소개
- 대학교 동아리 정회원 승급 프로젝트 (1인 개발)
- 턴제 RPG 전투 게임 프로토타입
- 전투, 스킬, 장비 부품 장착, 인벤토리, UI 시스템 구현

## 2. 개발 환경
- Unreal Engine 6.4
- C++ 기반
- 사용 플러그인 없음

## 3. 핵심 시스템
### 3.1 턴제 전투 상태 흐름 관리
### 3.2 턴제 전투 순서 관리
### 3.3 공격/스킬 사용 타겟 지정 시스템
### 3.4 장비/부품 장착 시스템
### 3.5 인벤토리/루팅 시스템
### 3.6 3.4, 3.5 시스템과 UI 연동

## 5. 주요 구현 포인트
- DataAsset 기반 확장 구조
- Delegate 기반 UI 갱신
- 즉발 / 투사체 공격/스킬 구분
- 장비 부품 장착 시의 스탯 반영
- 전투 결과에 따른 플레이어 캐릭터 HP/SP 저장

## 5. 문제 해결 사례
- 전투 유닛 스폰 위치 보정
- 투사체 스킬 종료 타이밍 처리
- 장비 변경 시 모델링/스탯 동기화
- UI 바인딩 타이밍 문제

## 6. 개선 예정
- BattleControlSubsystem 책임 분리
- TargetSelection 로직 분리
- Enemy AI 고도화
- Save/Load 시스템을 통한 진행도 저장
